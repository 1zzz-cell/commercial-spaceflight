结论先行：这类网站最该做的不是「更炫的行情屏」，而是「每个数字都能查证」的研究型站点。活动与会员是转化层，合规是骨架，不是页脚。

判断一 · 首页选数据驱动首屏只放 1 主标题 + 1 常驻风险条 + 3 张带来源条的数据卡 + 1 个入口组；活动作为一级导航与第 2 屏的「活动卡列表」存在，不做营销 banner。
判断二 · 合规是渲染约束32px 来源标注条、常驻不可关闭的风险条、6 类动作的强制勾选模态，都要落到组件类型、lint 规则与服务端令牌，而不是写在文案规范里。
判断三 · 围绕一个认知痛点建 IA该板块「概念相关 ≠ 业绩受益」：概念股数量远多于产业主体，且相当比例成分股未盈利。所以公司卡用三元状态、估值分位要按盈利/未盈利分组、公告原文必须一键直达。
一个反直觉的取舍：多数「投资活动站」会做成营销落地页（倒计时、名额进度条、收益案例、讲师战绩），但这恰恰是合规风险最高、与投教定位最冲突的方向。本方案明确禁用这些形态，把报名决策点前移到「主办方资质 + 活动性质 + 个人信息授权」的阅读上，放弃用稀缺性推动转化。
第二个反向声音：不要堆「概念股榜单」。题材热度和业绩传导落点并不一致，榜单反而放大误导。设计资源应投在「已量化业务占比 / 仅概念映射 / 未盈利」的区分与一手公告核对链路上。

6 · 关键使用流程

流程 ①　新访客首访 → 了解活动 → 完成报名

S1 首页（决策：是否理解研究参考定位；退出：关闭，无强制注册）→ S2 活动列表筛选（决策：读性质与主办方资质；退出：返回）→ S3 详情（决策：接受非投资建议 / 非邀约；来源提示：主办方资质带「来源｜核验时间｜口径」）→ S4 填写并逐项勾选个人信息授权（决策：用途/留存期/撤回；退出：放弃且不留存已填信息）→ S5 D 免责模态（不可遮罩关）勾选已知悉投资者教育性质 + 提交 → S6 回执（决策：下载 / 撤销）。

风险条全程 sticky；全程无数值、无名额进度、无倒计时。

流程 ②　查板块 → 下钻公司 → 核对公告原文 → 加入观察

S1 行情页读状态条 + 3 卡来源条（退出：仅浏览）→ S2 公司库按业务占比状态 / 产业链段筛选（决策：优先已量化业务占比；退出：清空）→ S3 详情识别三元状态，未盈利不读 PE，每卡 ★ 来源条 → S4 公告原文（来源提示：一手直达交易所；研报标二手·需核实原文；退出：返回详情）→ S5 加入观察（禁「买入 / 自选」措辞）→ 若下载研究卡触发 D → S6 观察列表（无排名、无整行着色）。

流程 ③　工具对比 → 导出研究卡

S1 筛选器（决策：条件写 URL 可分享）→ S2 结果表（★ 来源条 + caption；决策：≤3 家）→ S3 对比 / 估值分位（决策：盈利/未盈利分组，未盈利不进 PE 分位；退出：调条件）→ S4 D 导出免责模态（仅供研究参考、不构成投资建议、不得对外荐股）→ S5 研究卡自动附来源｜数据时间｜口径 + 免责全文 + --.-- 占位说明 + 生成时间 → 退出。

流程 ④　发帖 → 审核 → 发布 / 驳回

8.1 数据口径的两层澄清（避免误读）

本方案多处写「产品内禁写任何真实行情数值、一律 --.--」，指的是设计态 / 原型 / 方案文档：不把某个时点的数字硬编码进界面文案或截图，以免过期数字被当作当前数据。这不等于网站上线后永远只显示破折号——运行时应由合规授权的数据源提供数值，并逐项携带「来源名称 + 来源分级 + 数据时间（带时区）+ 口径 + 市场状态 + 延迟分钟数 + 免责版本」。任何缺失其中一项的响应都不渲染数值，回退为 --.-- 并保留来源条。这一区分是「不编造数据」与「产品可用」之间的边界。

一手来源（交易所公告、公司年报/季报、监管机构）可直接采信并标注机构名 + 发布日期；非一手来源（财经媒体、研报引用、第三方平台二次引用）必须标「需核实原文」，研报还需标注机构 + 发布时间，不得与一手来源同等处理。跨来源数值冲突时优先采信高层级来源并显式标注分歧。
